# REST API

Базовый адрес: `http://127.0.0.1:3001/api`. JSON в UTF-8; при изменениях обязателен заголовок `Content-Type: application/json`. Даты — ISO 8601 UTC.

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/health` | Работоспособность сервиса |
| GET | `/meta` | Категории, причины, статусы, каналы, теги и признак демоданных |
| GET | `/tickets` | Список с фильтрами и пагинацией |
| POST | `/tickets` | Создать обращение; первоначальная категория по ключевым словам |
| GET | `/tickets/:id` | Карточка с текстом, тегами и историей |
| PATCH | `/tickets/:id` | Изменить поля карточки с проверкой версии |
| POST | `/tickets/:id/classify` | Выполнить анализ ИИ и сохранить результат |
| GET | `/analytics` | Метрики, динамика, категории, причины, каналы и уведомления |
| GET | `/ai` | Соединение, готовность выбранной модели и список моделей |
| PUT | `/settings/model` | Выбрать установленную модель |
| POST | `/reports/summary` | Сформировать текстовый отчёт по фильтрам |
| GET | `/reports/export` | Скачать CSV |

## Общие фильтры

Одинаково работают для списка, аналитики, отчёта и экспорта:

| Параметр | Значения |
|---|---|
| `from`, `to` | `YYYY-MM-DD`, включительно. По умолчанию последние 30 дней |
| `q` | Поиск по тексту и автору, до 300 символов, либо номер обращения |
| `category` | `payment`, `access`, `technical`, `features`, `other`, `all` |
| `status` | `new`, `in_progress`, `resolved`, `all` |
| `priority` | `low`, `medium`, `high`, `all` |
| `channel` | `email`, `chat`, `web`, `phone`, `all` |
| `tag` | Точное имя тега без учёта регистра |
| `page` | Номер страницы от 1; для списка |
| `limit` | Размер страницы 1–100, по умолчанию 12; для списка |
| `format` | `tickets` или `summary`; только для экспорта |

Пример: `GET /api/tickets?from=2026-08-01&to=2026-08-31&category=payment&status=new&page=1&limit=12`.

Пустой результат списка: `{"items":[],"total":0,"page":1,"pages":0}`. При количестве страниц 0 пагинация не показывается.

## Создание обращения

`POST /api/tickets`

```json
{
  "subject": "Двойное списание",
  "body": "За подписку списали деньги два раза. Прошу проверить платёж.",
  "author": "Анна Иванова",
  "email": "anna@example.com",
  "channel": "email",
  "priority": "high",
  "tags": ["подписка"]
}
```

Обязательные поля: тема 3–200 символов, текст 5–12000, автор 2–100. Email необязателен. Канал по умолчанию `web`, приоритет `medium`, теги — пустой массив. Не более 10 тегов по 40 символов. Успех: HTTP 201, полная карточка с `id` и `version`.

После сохранения вызовите `POST /api/tickets/:id/classify` с телом `{}`. Результат содержит `source: "ai"` либо `source: "keywords"` и пояснение `ai_error`. Недоступный ИИ не отменяет сохранённое обращение. Анализ может изменить приоритет.

## Изменение карточки

`PATCH /api/tickets/1`

```json
{
  "version": 1,
  "status": "in_progress",
  "category": "payment",
  "reason": "Двойное списание",
  "priority": "high",
  "tags": ["подписка", "проверка"]
}
```

Передавайте только изменяемые поля и **текущую** `version` из GET. Если категория меняется без явного указания причины, используется первая причина новой категории. Список допустимых причин находится в `/meta`. Каждое обновление увеличивает версию. HTTP 409 означает, что карточка уже изменилась; получите её заново перед повторной правкой.

## Настройка модели

`PUT /api/settings/model` с телом `{"model":"qwen2.5:3b"}`. Выбранная модель должна быть установлена на сервере ИИ. Результат `GET /api/ai`:

```json
{
  "connected": true,
  "ready": true,
  "model": "qwen2.5:3b",
  "models": ["qwen2.5:3b"]
}
```

`connected` означает доступность сервера ИИ; `ready` означает наличие выбранной модели в списке. Это не гарантия успешной генерации при нехватке памяти или несовместимости модели.

## Отчёты

`POST /api/reports/summary?from=2026-08-01&to=2026-08-31` с телом `{}` возвращает `text`, `source`, `range`, `created_at`. При успешной генерации также есть `model`, при резервной сводке — `warning` (кроме пустой выборки).

`GET /api/reports/export?format=summary` возвращает CSV с заголовком скачивания. `format=tickets` — полные обращения. Фильтры передаются в строке запроса. CSV содержит UTF-8 BOM, разделитель `;`, переносы CRLF; кавычки и формулы экранируются.

## Ошибки

Ошибки возвращаются как `{"error":"Описание"}`; при ошибках валидации также доступно поле `details`.

| Код | Значение |
|---|---|
| 400 | Некорректные данные, даты, фильтры или причина |
| 403 | Изменяющий запрос с другого сайта |
| 404 | Обращение или маршрут не найдены |
| 409 | Конфликт версий |
| 413 | JSON больше 100 КБ |
| 415 | Изменяющий запрос не содержит JSON |
| 429 | Достигнут лимит параллельного анализа/отчёта |
| 500 | Внутренняя ошибка |

API не содержит авторизации и предназначен для локального рабочего пространства. Не публикуйте его напрямую в интернете.
