# Сигнал: анализ обращений пользователей с ИИ

Разработан работоспособный локальный веб-сервис для хранения и анализа обращений. Реализованы создание и просмотр обращений, подробная карточка, поиск по русскоязычному тексту, фильтрация, категории и теги, изменение статусов и история правок.

Для анализа используется локальный ИИ: модель определяет категорию, причину и приоритет обращения, составляет краткое описание и аналитические отчёты. При недоступности модели приложение продолжает работать, явно обозначая результаты классификации по ключевым словам.

Дашборд показывает динамику обращений, распределение по категориям, частые причины, среднее время решения и сравнение периодов. Поддержаны уведомления о резком росте категории, экспорт CSV и сохранение текстового отчёта. Интерфейс адаптирован для мобильного экрана.

Технологии: React, Node.js, Express, SQLite, Recharts, ИИ. В комплект входят исходный код, воспроизводимая установка зависимостей, инструкция по запуску, описание REST API и автоматические тесты. Для демонстрации предусмотрено заполнение пустой базы вымышленными обращениями.

Запуск: Node.js 24+, `npm ci`, `npm run build`, при необходимости `npm run seed`, затем `npm start`. Адрес приложения: http://127.0.0.1:3001. Для ИИ-функций нужен запущенный сервер ИИ с моделью qwen2.5:3b или другой совместимой текстовой моделью.

Проект предназначен для локальной работы. Авторизация и разграничение прав не входят в текущую версию.
